# NO FORM — Optical Disobedience

A procedural WebGL visual generator for live VJ sets. It runs a 26-second loop in five sections. Jump to any section or adjust the motion, camera, damage, flash, and speed while it plays.

## Run

Download [index.html](index.html) and open it in a browser with WebGL. The visuals run locally without external assets.

- **F** enters or exits fullscreen.
- **H** triggers a manual hit.
- **Space** pauses or resumes the loop.
- **1–3** switch palettes. **4–6** switch motion states.

Use the output controls to save a PNG still, record a WebM clip, or copy the GLSL shader. Recording and clipboard access depend on browser support.

The visuals can flash rapidly. Check the **Flash** setting before projecting.
