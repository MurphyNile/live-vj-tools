# BILLIONHAPPY / PINK SYSTEM FINAL

继续基于 Processing 4 + Sound + Syphon，输出 1056×576，供 Resolume Arena 接入。

## FINAL 本轮总优化

- **效果 1（SOLO）继续缩小**：主 skull 进一步收小，边缘留白更明确。
- **效果 3（CLONE）动态加强**：在保留边缘空隙的前提下，恢复并增强旋转与节奏动态。
- **FALL 空间层次精修**：强化纵深投影、远近尺寸差、速度层次与拖尾，整体更像真正的空间坠落。
- **FLASH / INVERT 现场手感优化**：
  - 爆闪更明显，自动与手动都更强。
  - 反色持续时间更长，更明显。
  - 反色不再依赖不稳定的反斜杠键位。
- **全场景节奏统一**：CLONE 变化、WALL / FALL 的排列变化统一改为 8-beat phrase，更像同一套演出系统。

## 推荐现场按键

- `1` SOLO / HERO
- `2` WALL / MATCH SWEEP
- `3` CLONE / MULTIPLY
- `4` FALL / SPACE DROP
- `R` 切换排列变体
- `N` 切换密度
- `A` 自动排列开关
- `SPACE` / `B` 手动打一拍
- `F` 自动爆闪开关
- `E` 手动爆闪
- `-` / `+` 调整爆闪强度
- `I` 自动反色开关
- `U` 手动反色
- `;` / `'` 调整反色强度
- `O` 自动光晕开关
- `[` / `]` 调整光晕强度
- `T` 测试节拍
- `C` 重新校准输入
- `,` / `.` 调整输入增益
- `D` HUD
- `?` 快捷键帮助
- `H` 按住黑场
- `0` 重置 FX
