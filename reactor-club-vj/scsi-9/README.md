# REACTOR Pres. SCSI-9

22 August 2026 · REACTOR, Shanghai, China · VJ by Murphy Nile. [Event announcement](https://mp.weixin.qq.com/s/ovMT49KhdGuJSbVBr7kleg)

The visual system uses live sound to drive particle fields, moving plates, and pulses of light. Signal Field includes a slower, sparser SCSI-9 mode and a more immediate response for the FEIYI / NAXIN mode.

The [materials](materials/) include the Resolume Arena composition, Signal Field Processing sketches, shaders, image sequences, and stills. The V16 performance sketch outputs at 1056 × 576 through Syphon. Open it in Processing 4 with the Sound and Syphon libraries. Relink local media paths when opening the Arena composition.
