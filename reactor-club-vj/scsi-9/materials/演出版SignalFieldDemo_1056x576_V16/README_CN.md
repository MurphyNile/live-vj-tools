# SIGNAL FIELD V16 — 1056 × 576 PERFORMANCE + DRUM FLASH

这是独立的半分辨率演出版。原来的 2112 × 1152 V13 母版没有被覆盖。
画面仍按原来的 2112 × 1152 设计坐标计算，然后缩放到 1056 × 576 输出。
Arena 放大两倍后，构图、粒子比例、线宽和辉光范围会尽量保持一致。

这是基于 V15 新建的独立工程，之前版本都不会被覆盖。

工程包含：

- `SignalFieldDemo_1056x576_V16.pde`：Processing 4 主程序
- `data/fluid.glsl`：MEMBRANE 着色器
- `data/sequence/A1.png–A16.png`：效果 7 的 16 张图像序列
- `README_CN.md`：运行说明

## V16 的主要变化

- FEIYI / NAXIN 模式的速度、弹性和瞬态强度明显提高。
- 强化模式采用更快的攻击和回落。鼓点出现时快速扩张、增亮和错位，鼓点结束后迅速收回，节拍之间保留黑场。
- 新增全局鼓点闪白、局部大范围闪烁和极少量一帧黑场。
- 闪烁只由 onset 和低频鼓点触发，不会自行匀速循环。
- 不同鼓点会在全屏闪、横向区域闪、纵向区域闪、局部柔光和不闪之间变化。
- `F` 控制全局及局部鼓点频闪。默认开启。
- 开启 `S` 后，红色扫描线也会跟随新的鼓点闪烁强度产生跳动。
- Syphon 源更新为 `SIGNAL_FIELD_1056x576_V16`。

## 继承自 V15 的现场控制

- `D` 面板改成清楚的大号 Mic 控制界面。
- 面板同时显示 `RAW MIC` 和 `VISUAL SIGNAL`。前者是麦克风真正听到的输入，后者才是送给画面的信号。
- `-` 降低 Mic 灵敏度，`=` 或 `+` 提高灵敏度。
- 新增默认开启的 `LIVE MIC GUARD`，按 `L` 可以开关。
- LIVE MIC 使用慢速环境基准，持续大音量会逐渐被视为背景。低频节拍有更高权重，中高频占主导的声音会被适度削弱。
- 开启 LIVE MIC 后，按 `C` 会进行 10 秒校准。校准时必须播放接近正式演出音量的音乐。

## 继承自 V14 的内容

- 保留锁定版效果 1–6 的图形、动态、背景闪烁、辉光和音频逻辑。
- 新增效果 7 `IMAGE SEQUENCE`，16 张图片在启动时一次性预载，播放过程中不会逐帧读取硬盘。
- 效果 7 的整体切换速率由声音能量控制；低频强化顺序推进，中高频只在少量瞬态中触发跳帧或一步短倒放。
- 强 onset 偶尔触发 1–2 帧暖白曝光；极少量强事件触发 1 帧黑场。不会持续闪烁。
- 部分切图通过 3–6 条宽横带分段显现，持续 6–12 帧；扫描保持黑白，不增加新颜色。
- 所有序列帧在内存中转为灰度，素材文件本身不被修改。

## 继承自锁定版的内容

- FIELD 的图形、聚散路径和缓动恢复为 V8。已移除 V12 的整屏连续翻面，不再快速反复压扁粒子平面。
- PLATES 的长短板块、实体面、轮廓面和慢速扫线恢复为 V8，不再使用 V12 的大面积暗面与小亮核结构。
- SCORE 的宽谱带、多频段主线、远距轮廓和全幅 strike 恢复为 V8。强瞬态偶尔触发一次短暂镜像或位移 feedback，不会常驻。
- V12 的稀有背景闪白、局部辉光、红色扫描闪烁、两种音乐模式、音频分析和 Syphon 输出全部保留。
- MEMBRANE、ASCII VEIL 与 PULSE 不做修改。
- 颜色仍为黑色与暖白。只有开启 `S` 后才出现红色扫描线。
- Syphon 输出中没有调试文字、标签和数字。

## 两种音乐模式

| 按键 | 模式 | 特点 |
| --- | --- | --- |
| `Q` | SCSI-9 | 速度较慢，事件变化较少，留白较多，动作停留时间更长。 |
| `W` | FEIYI / NAXIN | 鼓点响应明显更强，攻击和回落更快，聚散、错位、频闪和局部爆发更有节奏。 |

`E` 也会切换到 FEIYI / NAXIN 模式，方便保留原来的操作习惯。

## LIVE MIC 的实际作用

LIVE MIC 可以解决两类问题：

- 现场长期很响，画面一直停在最高强度。
- 观众声、讲话声和其他偏中高频的声音频繁触发大动作。

它不能真正识别人声。如果嘴离电脑内置麦克风很近，人声可能比远处音箱更强，仍有可能触发。最有效的做法还是使用指向性麦克风对准音箱，并远离讲话位置。现场可以看 `D` 面板进行判断：

- 说话时 `RAW MIC` 上升，但 `VISUAL SIGNAL` 明显低很多，说明保护有效。
- 两条同时接近满格，说明麦克风离人太近，或输入音量过高。先按 `-`，必要时降低 macOS 输入音量。

## 七个场景

| 按键 | 场景 | 当前声音关系 |
| --- | --- | --- |
| `1` | FIELD | 音量控制粒子数量与尺寸。低频和瞬态改变聚散，四组粒子在带状、散场、群落与斜向结构间缓慢变形。 |
| `2` | PLATES | 音量控制板块数量。各频段改变长短板块的尺寸和漂移，瞬态只对部分板块产生错位回声。 |
| `3` | SCORE | 频段历史形成宽谱带、多条完整主线和远距轮廓。较强瞬态偶尔触发一次镜像或轻微位移 feedback。 |
| `4` | MEMBRANE | 不同区域以不同速度活动和停顿。瞬态改变局部溶解阶段、碎度与边缘亮度。 |
| `5` | ASCII VEIL | 四种有机字符状态在轮廓、双层边缘、内部溶解和斜向裂变之间切换。 |
| `6` | PULSE | 只显示声音触发的大范围暖白光场。低频覆盖范围更大，高频更短、更亮，但不会产生小碎光点。 |
| `7` | IMAGE SEQUENCE | 声音能量控制 16 张图片的切换速率；onset 触发短促加速、分段扫描与稀有闪白。大多数时间保持顺序播放。 |

## 快速测试

1. 用 Processing 4 打开 `SignalFieldDemo_1056x576_V16.pde`。
2. 确认已安装 `Sound` 和 `Syphon` 库。
3. 运行后按 `T` 开启内置 124 BPM 测试信号。
4. 按 `Q` 测试 SCSI-9 模式，再按 `W` 测试强化模式。
5. 依次按 `1` 到 `7`，每个场景观察至少 15 秒。
6. 按空格或 `B` 可以手动触发一次声音事件。
7. 再按 `T` 回到麦克风，播放接近现场音量的音乐，然后按 `C` 校准十秒。

## 操作

| 按键 | 功能 |
| --- | --- |
| `1–7` | 切换七个场景 |
| `Q` | SCSI-9 模式 |
| `W / E` | FEIYI / NAXIN 模式 |
| `T` | 麦克风 / 测试信号 |
| `C` | 重新校准麦克风。LIVE MIC 开启时为 10 秒 |
| `- / =` | 降低 / 提高麦克风灵敏度。`+` 也可以提高 |
| `L` | 开关 LIVE MIC GUARD |

| `, / .` | 降低 / 提高瞬态阈值 |
| `R` | 手动改变整体构图 |
| `A` | 自动构图 / 锁定构图 |
| `N` | AUTO / SPARSE / DENSE |
| `S` | 开关红色音频扫描线与闪烁 |
| `V` | 开关 SCSI-9 中央字标保护区 |
| `D` | 开关 Processing 预览调试信息 |
| `B`、空格、鼠标 | 手动触发声音事件 |
| `Up / Down` | 调整整体亮度 |

## Syphon 到 Arena 7

Arena 的 Sources 中应显示：

`SignalFieldDemo_1056x576_V16 - SIGNAL_FIELD_1056x576_V16`

将它拖入空 Clip 并点击播放。Syphon 实际输出尺寸为 1056 × 576。
Arena 可以把它放大到 2112 × 1152，再与 3D 画面进行 Multiply。

为了降低长时间演出的卡顿风险，这个版本还复用了 FIELD 的临时数组和切场缓存，避免每帧或每次切场重复创建大对象。正式演出时建议关闭 `D` 调试信息。

按 `D` 可以在 Processing 预览中检查连接状态：

- `SYPHON SOURCE LIVE` 表示源已经发布
- `SYPHON CONNECTED` 表示 Arena 已连接
