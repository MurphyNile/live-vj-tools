# SIGNAL FIELD V8

新版只保留三个文件：

- `SignalFieldDemo.pde`：完整主程序，直接打开运行。
- `data/fluid.glsl`：黑白流体场。
- `README_CN.md`：当前说明。

之前压缩包中的多个 `.pde` 是 Processing 的代码分页，不是多个视觉版本。V8 仍然只有一个主程序文件。

## 视觉规则

- 画面固定为黑色和更透亮的暖白色。
- 只有按 `S` 后才出现红色扫描线。
- Syphon 输出中没有数字、标签和调试文字。
- 调试信息默认隐藏，只在 Processing 预览中按 `D` 显示。
- 所有构图变化都通过位置、速度、尺度插值完成，不会每帧随机跳动。

## 五个模式

| 按键 | 模式 | 画面变化 |
| --- | --- | --- |
| `1` | FIELD | 点、圆和短条在成列、成带、成团、散开之间连续变化。粒子群会形成不断移动的大型包围框，并在冲击时留下短促运动痕迹。 |
| `2` | PLATES | 大平面在横条、竖条、块面和自由排布之间移动。低频推动背景块面，瞬态产生克制的错位回声。 |
| `3` | SCORE | 真实五频段历史形成占据画面的大尺度主谱带、远距离回声轮廓和少量全幅线条。已移除细小块面。 |
| `4` | MEMBRANE | 完全取消几何蒙版。软边有机场决定聚散范围，内部由流线、细碎断层和随机空洞构成。声音推动流向和碎片密度。 |
| `5` | ASCII VEIL | 大面积字符团块持续滚动。瞬态打开裂缝并产生更强的分段位移、块状 glitch 和局部溶解。 |

## 聚散和声音关系

- 每两个有效瞬态，系统会在聚集与散开之间转换。
- 低频推动大尺度扩张。
- 中频改变形体弯曲和移动速度。
- 高频增加细节，但不会改变整体色彩。
- 音量较低时只显示少量大形体和黑场。
- 音量增强后才逐步增加元素数量。
- 构图只改变目标位置，元素会平滑移动到新位置。
- 开启 `S` 后，高频提高扫描速度与线宽，整体音量提高红线亮度。瞬态会触发扫描跳位、断裂亮段和短促暖白闪烁。

## 基本测试

1. 打开 `SignalFieldDemo.pde`。
2. 确认已安装 Processing 4 的 Sound 和 Syphon 库。
3. 运行后先按 `T`，使用内置 124 BPM 测试信号。
4. 依次按 `1`、`2`、`3`、`4`、`5`。
5. 每个模式至少观察 10 秒，测试信号会循环经过稀疏、中等、密集和峰值。
6. 按 `R` 手动改变排布，按空格手动触发聚散。
7. 再按 `T` 回到麦克风，然后播放音乐并按 `C` 校准三秒。

## 操作

| 按键 | 功能 |
| --- | --- |
| `1–5` | 切换五个模式，使用平滑淡入 |
| `Q / W / E` | SCSI-9 / FEIYI / NAXIN 动态预设 |
| `T` | 麦克风 / 测试信号 |
| `C` | 重新校准麦克风 |
| `[ / ]` | 降低 / 提高麦克风灵敏度 |
| `, / .` | 降低 / 提高瞬态阈值 |
| `R` | 手动切换构图 |
| `A` | 自动构图 / 锁定构图 |
| `N` | AUTO / SPARSE / DENSE |
| `S` | 开关音频响应红色扫描线与画面闪烁，默认关闭 |
| `V` | 开关 SCSI-9 中央字标保护区 |
| `D` | 开关预览调试信息，默认隐藏 |
| `B`、空格、鼠标 | 手动触发聚散和音频脉冲 |
| `Up / Down` | 调整整体亮度 |

## 三个音乐人预设

- `Q` SCSI-9：最慢，留白最多，构图每四个有效瞬态变化。
- `W` FEIYI：中等速度和密度，构图每三个有效瞬态变化。
- `E` NAXIN：移动更快，细节更多，构图每两个有效瞬态变化。

预设不会改变颜色。

## Syphon 到 Arena 7

Arena 的 Sources 中已经能看到：

`SignalFieldDemo - SIGNAL_FIELD_2112x1152`

这就是 Processing 输出。把它拖进一个空 Clip，然后点击该 Clip 播放。只在 Sources 列表里看见名字，不代表它已经进入图层。

按 `D` 后可以查看状态：

- `SYPHON SOURCE LIVE`：源已经发布，Arena 还没有连接这个 Clip。
- `SYPHON CONNECTED`：Arena 已连接。

黑底叠加建议先用 Add 或 Screen，Opacity 从 18%–35% 开始。需要避开 SCSI-9 中央字标时按 `V`。
