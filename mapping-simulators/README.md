# Mapping Simulators

Two browser previews for checking how video or still images read on architectural surfaces before an on-site test. Both use approximate venue geometry. Use a browser with WebGL. Download each HTML file and open it locally, then load your own media from the interface.

## XiaoTongCang, West Bund Shanghai

Preview video or still images on the cylindrical XiaoTongCang (小砼仓) structure. The Chinese-language interface accepts a local file and lets you adjust geometry and mapping zones. [XiaoTongCang simulator](xiaotongcang/index.html)

## Longemont Wrap-Around Screen, Shanghai

Built to preview *Boundary Still Loading* for ACM SIGGRAPH DAC Urban Digital Canvas Shanghai at the 3rd Shanghai International Light Festival. Load separate files for the left (2496 × 1984) and right (1024 × 1984) faces. Adjust viewing angle, eye height, and distance to check how the two images meet at the corner. [Longemont simulator](longemont/index.html) · [Exhibition listing](https://dac.siggraph.org/artwork/boundary-still-loading/)

Both HTML files include Three.js r128. [MIT license](THREE-LICENSE.txt)
